High-frame rate infrared cameras from wii remotes used for outdoor light sources
The NIH paper seems to address saturation from sunlight
https://pmc.ncbi.nlm.nih.gov/articles/PMC7218719/

There have been several wii whiteboard projects that use the wii remote as a bluetooth-connected IR camera
These projects are quite old. They track a infrared pen (IR led on a stick)

Other commodity equipment like smart phones sometimes have IR remote/recievers. If a TV remote can work outside,
this can at least help with node-to-node communication. Phones are cheap enough, that if we are able to run our own linux
on there (pine64 makes this easy, but even the pro version of the hardware is pretty mid compared to a flagship phone
which can probably handle a much higher workload). The phone can talk to the flight controller over USB Serial,
perform sensor fusion etc.
